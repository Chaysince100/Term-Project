# Project Term - ร้านบูรพาสปาเก็ตตี้ (Black Sheep in the Garden)

ระบบสารสนเทศร้านอาหารบูรพาสปาเก็ตตี้ พัฒนาด้วย PHP และ MySQL (ฐานข้อมูล utf8mb4_general_ci) 
โดยใช้ Template Editorial (HTML5 UP)

## คุณสมบัติระบบ (Features)
- **ข้อมูลพื้นฐานกลุ่ม Setup:** หมวดหมู่สินค้า (Category), ประเภทการชำระเงิน (Paytype), หมายเลขโต๊ะ (Table), ประเภทค่าสาธารณูปโภค (Expense Type)
- **ข้อมูลสินค้า (Product):** ระบบเพิ่ม ค้นหา แก้ไข และ **Zoom ประวัติการขายสินค้า**
- **ข้อมูลการทำงาน (Sales & POS):** บันทึกการขาย (บันทึกจำนวนลูกค้า), สั่งอาหารเพิ่มในบิลเดิม, รับชำระเงิน, และ **Zoom เป็นใบเสร็จรับเงิน (พิมพ์ใบเสร็จ)**
- **รายงาน (Reports):**
  1. สรุปการขายระหว่างวันที่ - วันที่ (แสดงสินค้า ยอดขายรวม มูลค่าการขาย และสรุปยอดรวมทั้งหมด)
  2. รายงานกำไรขาดทุนเบื้องต้น (รายได้จากการขาย, ค่าใช้จ่ายต้นทุนสินค้า, ค่าใช้จ่ายสาธารณูปโภค)

## วิธีติดตั้งและใช้งาน
1. นำไฟล์ฐานข้อมูล `burapa_spaghetti.sql` ไป Import ผ่าน phpMyAdmin
2. วางโฟลเดอร์โปรเจกต์ใน `C:/xampp/htdocs/`
3. เข้าใช้งานผ่านบราวเซอร์ที่ `http://localhost/Projectterm/` หรือ `http://localhost/burapa_spaghetti/`
